# Corpus

Coloca aquí 15–20 archivos `.md`: tus runbooks, notas de pipelines CI/CD,
procedimientos de rollback, post-mortems, documentación pública de GitHub Actions / Terraform.

Reglas:
- Nada con secretos, tokens ni datos personales (el corpus se sube a git).
- Si usas material de un empleador anterior, anonimízalo o no lo subas.
- Mezcla tamaños: algunos documentos cortos y otros largos (el D4 los necesita).
